## 💄 API REST - E-commerce de Cosméticos

Este projeto consiste no desenvolvimento de uma API REST completa para um sistema de venda de produtos cosméticos, focado em organização de código, boas práticas de arquitetura e integração eficiente com banco de dados.

A aplicação foi estruturada seguindo o padrão de camadas (**Model, Repository, Controller e Database**), garantindo escalabilidade, manutenção facilitada e separação clara de responsabilidades.

---

## 🚀 Tecnologias utilizadas

- **Node.js** → Ambiente de execução JavaScript no servidor  
- **TypeScript** → Tipagem estática, maior segurança e legibilidade no código  
- **Express** → Criação de rotas HTTP e estrutura da API  
- **Better-SQLite3** → Banco de dados leve e eficiente, sem necessidade de instalação externa  
- **Nodemon** → Atualização automática do servidor durante o desenvolvimento  
- **ts-node** → Execução direta de arquivos TypeScript  

---

## 🧠 Arquitetura do projeto

O sistema foi dividido em camadas bem definidas:

- **Model**  
  Responsável pela definição das entidades e estrutura de dados da aplicação  

- **Repository**  
  Gerencia a comunicação com o banco de dados, incluindo criação de tabelas e consultas (SELECTs)  

- **Controller**  
  Responsável pela lógica da API REST, validações e comunicação com o frontend  

- **Database**  
  Configuração e integração com o SQLite  

Essa abordagem melhora a organização do código e segue princípios como separação de responsabilidades e reutilização.

---

## 📌 Funcionalidades principais

- Cadastro de produtos cosméticos  
- Listagem de produtos  
- Validação de dados nas requisições  
- Integração com banco de dados relacional  
- Estrutura preparada para expansão (ex: autenticação, carrinho e pedidos)  

---

## 💡 Diferenciais do projeto

- Uso de TypeScript para maior robustez  
- Arquitetura em camadas (padrão profissional)  
- Banco de dados leve e de fácil integração  
- Código organizado e preparado para crescimento
